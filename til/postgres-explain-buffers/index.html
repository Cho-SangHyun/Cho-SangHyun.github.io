EXPLAIN (ANALYZE, BUFFERS)

작성 2026년 10월 4일1분 읽기

  • #database
  • #postgresql

EXPLAIN (ANALYZE, BUFFERS)를 쓰면 실행 시간뿐 아니라 shared buffer hit/read 수까지 보여 준다. 캐시 적중 여부를 볼 때 유용하다.

EXPLAIN (ANALYZE, BUFFERS) SELECT * FROM orders WHERE user_id = 42;
