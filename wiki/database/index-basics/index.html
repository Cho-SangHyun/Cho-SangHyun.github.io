B-Tree 인덱스

대부분의 RDBMS 기본 인덱스. 정렬된 상태를 유지하므로 범위 검색과 정렬에 강하다.

복합 인덱스 컬럼 순서

  1. 동등 조건(=)으로 쓰는 컬럼을 앞에
  2. 범위 조건(>, BETWEEN)은 뒤에
  3. 선택도(cardinality)가 높은 컬럼을 우선 고려
CREATE INDEX idx_orders_user_created ON orders (user_id, created_at);

커버링 인덱스

쿼리에 필요한 컬럼이 모두 인덱스에 있으면 테이블을 읽지 않고 인덱스만으로 결과를 만든다.
